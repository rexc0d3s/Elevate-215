# # School Data Dashboard — SPEC

Build a simple dashboard for Elevate 215 that pulls school performance information and school notes into one place so Stacy can quickly review a school’s latest information.

Input: Excel sheets/spreadsheets from Renée containing school names, performance metrics, results/numbers, dates, statuses, and school visit/update notes; sample files are attached.

Output: organized school data showing each school’s performance, latest update, status, and notes, with anything missing or outdated clearly flagged.

Done when: every school, number, date, and note matches the source files exactly—nothing is changed, guessed, or dropped.
