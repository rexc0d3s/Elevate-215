# School Data Dashboard — SPEC v2

Build a simple, read-only dashboard for Elevate 215 that organizes school information and performance data so Stacy can quickly review each school’s most current information.

**Input:** School Rollup spreadsheet containing school information, enrollment, demographics, performance data, residuals, performance bands, and classifications.

**Output:** Clearly labeled school information showing:

* School overview
* Enrollment and student information
* Academic performance
* Overall performance
* School classifications
* Latest update/date when available
* Missing or outdated information

**Data rules:** Match the source exactly. Do not change, guess, or invent values. Preserve missing data, zeros, performance bands, and classifications.

**Future notes:** Allow Renée’s school visit/update notes to connect to the correct school using the School Number, including the note date and update information.

**Done when:** Every school and data value matches the source exactly, every required field is clearly labeled, missing/outdated information is flagged, filters make schools easy to find, each school can be viewed individually, and nothing is guessed, changed, or dropped.
